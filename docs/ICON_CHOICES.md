# Remix Icon choices

The interface uses Remix Icon's outlined (`-line`) style throughout. It keeps the visual language calm and readable while labels provide the meaning.

| Use case            | Icon                                        | Reason                                                               |
| ------------------- | ------------------------------------------- | -------------------------------------------------------------------- |
| I lost a pet        | `ri-search-eye-line`                        | Signals that the pet is missing and the person needs to look for it. |
| I saw a pet         | `ri-eye-line`                               | States the sighting action directly.                                 |
| I found a pet       | `ri-home-heart-line`                        | Connects a safe pet with returning it to its family.                 |
| Nearby pets         | `ri-map-pin-2-line`                         | Signals place-based browsing.                                        |
| Choose an area      | `ri-map-pin-line`                           | Makes the location setting action clear.                             |
| Sign in             | `ri-user-3-line`                            | Identifies account access without implying a password.               |
| Report quickly      | `ri-time-line`                              | Reinforces that time matters.                                        |
| Protect privacy     | `ri-shield-check-line`                      | Communicates secure, protected information.                          |
| Help neighbours act | `ri-community-line`                         | Represents the local community working together.                     |
| Forward and back    | `ri-arrow-right-line`, `ri-arrow-left-line` | Familiar directional navigation cues.                                |
