# Write practical copy

## Titles and labels

- Name the thing directly.
- Use one clear title per section or card.
- Add an eyebrow, label, or number only when it provides useful context.

## Descriptions and body copy

- Explain what something is, does, or means in plain language.
- Include enough detail to be useful, but do not repeat the title or describe what is already obvious.
- Use concrete examples, accurate product names, and connected sentences.
- Make calls to action specific and useful.

Avoid:

| Pattern | Example | Suggested replacement |
| --- | --- | --- |
| Forced contrasts | "The wheel as a compass, not a contract." | "Use the color wheel to find colors that work together." |
| Poetic but meaningless claims | "Make a room feel inevitable." | "Create a space you feel good living in." |
| Clever but unclear headings | "The shape of the day" | "Agenda" |
| Vague section names | "What we make together" | "Team skills" |
| Artificial parallelism | "Three examples. Three independent ideas." | "Examples" |
| Self-important framing | "A prompt worth reusing" | "Example prompt" |
| Decorative taglines | "The work without the noise" | "Work board" |
| Vague calls to action | "Point people to the owned surface" | "Share the owned surfaces" |
| Dramatic sentence fragments | "A button moves. A label changes." | "The interface updates as you interact with it." |
| Disconnected punchy sentences | "A button moves. A label changes." | "The interface responds to your actions." |
